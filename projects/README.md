# Projects

Most Python drivers accept the following **flags**:

| flag        | output                      | destination           |
| ----------- | --------------------------- | --------------------- |
| `--book`    | figure data for book        | `results/`            |
| `--animate` | animation frames for slides | `results/animations/` |
| _(none)_    | inline visualization        | —                     |

> [!NOTE]
> The `README.md` in each project is an AI-generated dump used to communicate and understand the code during the ongoing development. It is not reviewed, not intended for long-term use, and will be removed later.
