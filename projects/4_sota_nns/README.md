# State-of-the-art neural networks

Showcase drivers that run pretrained state-of-the-art models to illustrate what mature architectures deliver out of the box for **Chapter 4 (Neural Network Architectures)**.

## Drivers

- `sota_classification.py`
  predicts the top-k class labels for an image.
- `sota_objectdetection.py`
  detects objects and draws labeled bounding boxes.
- `sota_segmentation.py`
  assigns a class to every pixel and overlays the masks.
